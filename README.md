#  Tax Calculator with Python

> 🎓 **Academic Project**: โปรเจกต์นี้จัดทำขึ้นเพื่อเป็นส่วนหนึ่งของการเรียนและการส่งงานอาจารย์ โดยมุ่งเน้นการศึกษาและสาธิตการเขียนโปรแกรมด้วยภาษา Python ในเรื่องการใช้ตรรกะเงื่อนไข (Conditional Statements) การรับค่าข้อมูล (User Input) และการคำนวณทาง математика/ภาษี

---

## 🚀 คุณสมบัติหลัก (Features)

* คำนวณภาษีเงินได้ตามอัตราก้าวหน้า/ขั้นบันได
* รองรับการรับข้อมูลรายได้จากผู้ใช้งานผ่าน Command Line Interface (CLI)
* แสดงผลสรุปยอดภาษีที่ต้องชำระอย่างชัดเจน
* โค้ดมีการจัดโครงสร้างให้อ่านเข้าใจง่าย เหมาะสำหรับเรียนรู้พื้นฐาน Python

---

## 📋 ความต้องการของระบบ (Prerequisites)

* **Python 3.x** ขึ้นไป (สามารถดาวน์โหลดได้ที่ [python.org](https://www.python.org/))

---

## ⚙️ วิธีการติดตั้งและใช้งาน (Installation & Usage)

1. **Clone Repository นี้ไปยังเครื่องของคุณ:**
   ```bash
   git clone https://github.com/Nattapong5361/Tax-calculator-with-python.git
   ```

2. **เข้าไปยังโฟลเดอร์โปรเจกต์:**
   ```bash
   cd Tax-calculator-with-python
   ```

3. **รันโปรแกรม:**
   ```bash
   python main.py
   ```
   *(หมายเหตุ: เปลี่ยน `main.py` เป็นชื่อไฟล์หลักของคุณ เช่น `tax_calculator.py` หากใช้ชื่ออื่น)*
